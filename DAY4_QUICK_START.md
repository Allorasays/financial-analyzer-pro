## 🚀 **How to Use:**

### **1. Add Your First Position**
- Click "➕ Add New Position" expander
- Enter stock symbol (e.g., AAPL, MSFT, GOOGL)
- Specify number of shares
- Set cost basis (purchase price)
- Add optional notes
- Click "Add Position"

### **2. View Your Portfolio**
- **Detailed View**: See all position details with current prices
- **Compact View**: Quick tabular overview
- **Analytics View**: Interactive charts and performance metrics

### **3. Track Performance**
- Real-time portfolio value updates
- P&L calculations for each position
- Overall portfolio performance metrics
- Performance vs S&P 500 comparison
