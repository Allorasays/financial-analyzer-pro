## 📋 **Step-by-Step Deployment**

### **Step 1: Go to Render Dashboard**

1. Navigate to: https://dashboard.render.com
2. Sign in (or create account if needed)
3. Connect your GitHub account if not already connected

---

### **Step 2: Create New Blueprint**

1. Click **"New +"** button (top right)
2. Select **"Blueprint"**
3. You'll see: "Create a new Blueprint from a Git repository"

---

### **Step 3: Connect Repository**

1. **Connect Repository**: 
   - If not connected, click "Connect GitHub" and authorize
   - Select: `Allorasays/financial-analyzer-pro`
   
2. **Select Branch**:
   - Branch: `complete-app-restoration`
   
3. **Blueprint File**:
   - File: `render_final.yaml`
   - Render will auto-detect it

4. Click **"Apply"**

---

### **Step 4: Review Services**

Render will show 3 services to be created:

1. **`moneta-backend-api`** (Web Service)
   - FastAPI backend
   - Port: Auto-assigned
   - Plan: Free

2. **`moneta-web-dashboard`** (Web Service)
   - Streamlit dashboard
   - Port: Auto-assigned
   - Plan: Free

3. **`daily-predictions-validation`** (Cron Job) ⭐ NEW
   - Runs daily at 11 PM UTC
   - Makes 10 predictions per day
   - Validates pending predictions

---

### **Step 5: Set Environment Variables**

**For `moneta-backend-api` service:**

Go to the service → Environment tab → Add:

- `TIINGO_API_KEY` = (your Tiingo API key)
- `ALPHAVANTAGE_API_KEY` = (your Alpha Vantage key)
- `FRED_API_KEY` = (your FRED API key)
- `NEWSAPI_KEY` = (your NewsAPI key - optional)

**Note**: `SECRET_KEY` will be auto-generated by Render ✅

**For `daily-predictions-validation` cron job:**

Environment variables are already set in `render_final.yaml`:
- `API_BASE_URL` = `https://moneta-backend-api.onrender.com` ✅
- `RENDER` = `true` ✅
- `PYTHON_VERSION` = `3.11.9` ✅

---

### **Step 6: Deploy**

1. Click **"Apply"** on the Blueprint page
2. Render will start building all 3 services
3. **Build time**: ~5-10 minutes for first deployment

## 🔧 **Troubleshooting**

### **Issue: Build Fails**

**Check logs for:**
- Missing dependencies → Check `requirements.txt`
- Python version → Should be 3.11.9
- Import errors → Check file paths

**Solution:**
- Review build logs
- Fix any import errors
- Re-deploy

### **Issue: API Not Responding**

**Check:**
- Service status (should be "Live")
- Environment variables set correctly
- API keys are valid

**Solution:**
- Check service logs
- Verify environment variables
- Test API keys manually

### **Issue: Cron Job Not Running**

**Check:**
- Cron job exists in dashboard
- Schedule is correct (`0 23 * * *`)
- Environment variables set

**Solution:**
- Click "Run Now" to test manually
- Check cron job logs
- Verify `API_BASE_URL` is correct

### **Issue: Predictions Not Being Stored**

**Check:**
- Backend API logs for errors
- Database directory permissions
- `prediction_tracker.py` import working

**Solution:**
- Check backend logs
- Verify database path is writable
- Test prediction endpoint manually
